Fonctionnalités avancées

🔀 Bascule intelligente

Passez d'un agent ou modèle à l'autre en conservant l'historique et le résumé du travail effectué.

📐 Multi-dispositions

1 session, 2 colonnes, 2 lignes ou grille 2×2 pour travailler sur plusieurs tâches en parallèle.

🌿 Worktrees Git

Isolez chaque session dans sa propre branche git et son dossier de travail sans polluer votre branche principale.

🖥️ Application native

Application de bureau macOS (Apple Silicon & Intel) avec raccourcis clavier natifs et icône dans la barre des menus.
